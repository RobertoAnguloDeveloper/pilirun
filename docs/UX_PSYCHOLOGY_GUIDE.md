# Why PiliRun looks and behaves this way

## Start with one clear action

The camp shows the chosen world and a single high-contrast play button. Secondary actions remain available without competing for attention. The player does not have to complete setup or create an account before the first run.

## Give creation a home

Characters, tracks and music have dedicated spaces. Each editor pairs a visible artifact with a short set of controls and an explicit save action. A player can make a small change and immediately see what it will affect.

## Make the character recognizable

Pili's orange silhouette, cream face and green scarf remain readable in the game and in small previews. Simple geometry reduces visual noise and rendering cost. Photo and pixel-art characters let the user replace that identity without changing the rules of play.

## Support confidence

Selected worlds and characters have both visual and textual indicators. Form errors explain the next useful action. Save messages describe the result only after persistence succeeds. Empty statistics state that the first adventure is still ahead.

## Keep returning pleasant

The diary rewards accumulated experience without streak pressure, countdown offers or artificial scarcity. A failed run still contributes distance and a memory. Pausing is prominent and has no penalty.

## Respect attention and agency

Sound starts through an explicit gesture. Music, effect level and effect pitch are adjustable. Menus do not interrupt an existing track. There are no notifications, external uploads, tracking scripts or social pressure mechanisms.

These are design intentions, not measured behavioral claims. Real player testing should validate how well they work across ages, motor abilities and devices.
